# JavaScript Pro

**JavaScript Pro** is an intermediate-level JavaScript learning repository created by coding along with a YouTube tutorial series by **Stephen Garcia**.  
The focus of this project is to move beyond JavaScript fundamentals and dive into **core language concepts and Object-Oriented Programming (OOP)** as they are applied in real-world JavaScript.

> This repository is for learning and practice purposes. The code is written while following along with the tutorial and may include personal experimentation and notes.

---

##  About the Project

Unlike beginner JavaScript tutorials that focus on syntax and basic control flow, this project emphasizes **how JavaScript works under the hood** and how to structure code using **OOP principles**.

The tutorial series refers to this stage as **“JavaScript Pro”** because it concentrates on intermediate concepts that are essential for building maintainable and scalable applications.

---

##  Concepts Covered

This repository includes practical examples and exercises covering:

### Core JavaScript Concepts
- Objects and object behavior
- Functions as first-class objects
- Prototypes and prototype chaining
- The `this` keyword
- Scope and closures

### Object-Oriented Programming (OOP)
- Classes and constructors
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Prototypes vs classical OOP

### Modern JavaScript
- ES6+ syntax
- Modules (import / export)
- Code organization patterns
